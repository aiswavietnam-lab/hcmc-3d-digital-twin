# HCMC_3D_DIGITAL_TWIN — Bản Sao Số 3D TP. Hồ Chí Minh (WebGL Three.js r128)

Trình xem tương tác 3D trực tuyến cho **Bản Sao Số 3D TP. Hồ Chí Minh (`HCMC_3D_DIGITAL_TWIN`)**:
- **Link cố định GitHub Pages:** `https://aiswavietnam-lab.github.io/hcmc-3d-digital-twin/`
- **Hệ tọa độ chuẩn (`EPSG:32648`):** Gốc `(0, 0, 0)` tại Tâm Quận 1 (`10.7798°N, 106.6990°E`), `+X` hướng Đông, `+Y` cao độ mét MSL, `+Z` hướng Nam.
- **Dữ liệu đồng bộ từ Google Drive:** Các ô lưới `2×2 km` Ring 1 (`.glb` + `_scatter_trees.bin` 4 loài cây nhiệt đới Sài Gòn + nền vệ tinh + địa danh biểu tượng).
